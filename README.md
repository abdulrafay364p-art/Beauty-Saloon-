# Aurelle Maison de Beauté ✨

A modern and elegant beauty salon website designed to showcase salon services, packages, brand identity, and provide an easy way for customers to book appointments.

## 🚀 Features

- Premium luxury salon design
- Fully responsive layout (Mobile, Tablet, Desktop)
- Elegant hero section with booking call-to-action
- About salon section
- Beauty services showcase
- Service packages and pricing section
- Professional salon gallery
- Customer reviews/testimonials
- Appointment booking form
- Contact section with social links
- WhatsApp booking button
- SEO-friendly structure

## 💄 Services Included

- Hair Styling
- Hair Treatments
- Skincare
- Makeup Services
- Beauty Treatments
- Spa & Relaxation Services

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
